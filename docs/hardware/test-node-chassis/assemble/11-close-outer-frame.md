# 11. Close the outer frame

<p class="pf-step-count">Assembly · Step 11 of 19</p>

Build the complete upper rectangle on the bench, then lower it onto all four
posts together.

## Do this

1. Arrange the four upper rails as a flat rectangle using the same
   operator/device/left/right layout as the lower frame.
2. Confirm their loaded grooves still face the directions set in Steps 2 and 3.
3. Install the four metal three-way connectors and snug them only enough to
   hold the upper ring together.
4. With one hand on each side—or with a helper—lift the complete upper ring
   above the four posts.
5. Keep the camera frame below the ring and all four upper joint plates clear.
6. Align all four post ends before lowering any corner.
7. Lower the ring evenly. Stop and realign if one post resists.
8. Bring every upper horizontal rail flush to its adjacent post face.
9. Snug the connector screws. Do not apply final torque yet.
