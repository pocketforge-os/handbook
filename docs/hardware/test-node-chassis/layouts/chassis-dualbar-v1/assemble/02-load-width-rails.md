# 2. Load the four width rails

<p class="pf-step-count">Assembly · Step 2 of 17</p>

<p class="pf-profile-banner" data-layout-id="chassis-dualbar-v1"><strong>Compatible topology:</strong> Current registered device packs <span>·</span> <code>chassis-dualbar-v1</code></p>

Put six active channel bars into three labeled width rails. The lower operator
rail deliberately receives **none**.

## Get these parts

<ul class="pf-part-list">
  <li><span class="pf-part-tag pf-part-tag--aluminum">Aluminum</span><span><strong>4 × 306 mm labeled width rails</strong><small><code>WIDTH-O-L</code>, <code>WIDTH-O-U</code>, <code>WIDTH-D-L</code>, and <code>WIDTH-D-U</code></small></span></li>
  <li><span class="pf-part-tag pf-part-tag--printed">Printed</span><span><strong>6 × compact M3 channel bars</strong><small>Ordinary M3 nut seated in each carrier</small></span></li>
  <li><span class="pf-part-tag pf-part-tag--fastener">M3</span><span><strong>6 × M3 × 12 mm screws and wide washers</strong><small>Temporary handles now; active mounting hardware later</small></span></li>
</ul>

<div class="pf-picture-key" role="group" aria-label="Width-rail preload picture annotations">
  <p class="pf-picture-key__title">Read the picture</p>
  <ul>
    <li><span class="pf-cue pf-cue--orange">Orange bars</span><span>These six active bars will fasten the placard and DUT-holder links.</span></li>
    <li><span class="pf-cue pf-cue--blue">Blue labels</span><span>Match every tape code and count before moving to the next rail.</span></li>
    <li><span class="pf-cue pf-cue--silver">Silver rails</span><span>All four pieces are 306 mm; identity and loaded groove distinguish them.</span></li>
  </ul>
</div>

## Do this

1. Lay the four width rails beside the drawing with their tape labels visible.
2. Leave `WIDTH-O-L` empty. It receives **0** channel bars.
3. Choose the groove on `WIDTH-O-U` that will face the operator, outside the
   finished frame. Insert **2** bars through a cut end.
4. Choose the groove on `WIDTH-D-L` that will face the operator, toward the
   frame interior. Insert **2** bars.
5. Load `WIDTH-D-U` the same way with **2** bars in its future
   operator-facing interior groove.
6. Leave every handle only one turn into its nut. Spread each pair apart so
   the bars cannot be confused with one another.
7. Read the tape codes again and count **six active width-rail bars**.

</div>

`WIDTH-D-U` each have 2; all six slide freely and no other width-rail groove is
loaded.
