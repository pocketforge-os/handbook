# 3. Load the four depth rails

<p class="pf-step-count">Assembly · Step 3 of 17</p>

<p class="pf-profile-banner" data-guide-device="trimui-smart-pro-s" data-layout-id="chassis-dualbar-v1"><strong>Compatible DUT:</strong> TrimUI Smart Pro S <span>·</span> <code>chassis-dualbar-v1</code></p>

Load one active printed-joint position into every depth rail, add the four
power-strip positions to the lower operator-right rail, then park one
blue-tagged spare in every depth rail.

<ul class="pf-part-list">

  <li><span class="pf-part-tag pf-part-tag--printed">Printed</span><span><strong>12 × compact M3 channel bars</strong><small>Four active printed-joint bars, four active power-strip bars, and four parked replacements</small></span></li>

## Do this

1. Lay out the four depth rails by tape code and identify `DEPTH-R-L`: the
   lower right rail when viewed from the operator side.
2. Choose the side groove on `DEPTH-R-L` that will face the frame interior.
   Insert **4 active power-strip bars + 1 parked bar**. Leave the active
   screws untagged and tag only the parked screw blue.
3. Put **1 active joint bar** into the upward groove of each lower rail:
   `DEPTH-L-L` and `DEPTH-R-L`.
4. Put **1 active joint bar** into the downward groove of each upper rail:
   `DEPTH-L-U` and `DEPTH-R-U`.
5. Put **1 parked bar** in the future interior-facing side groove of each of
   the remaining three depth rails and tag each parked screw blue.
6. Move each parked bar near a cut end but keep it fully behind the groove
   lips. Leave its handle only finger-snug.
7. Count **eight active + four parked = 12 depth-rail bars**.
